# W5 · 10 个真实提问

> 这是本周唯一的尺子。**别临时编问题**——编出来的问题会不自觉地贴合你写的 description，
> 测不出误调用。这里的 10 条按"该不该调、调哪个"分了三类，比例是刻意配的。

## 用法

- `期望工具` 填工具名，或 `none`（表示这种情况下**不该**调用任何工具）
- `probe.py` 会读这张表的四列，跑完给你逐条判定和准确率
- 改表格时保持 `|` 分隔，前两行（表头 + 分隔线）别删

| id | 问题 | 期望工具 | 说明 |
|---|---|---|---|
| Q1 | 线性回归的正规方程是什么？ | search_notes | 典型检索题：知道概念，不知道在哪一节 |
| Q2 | 根据 week3.md 里 6.2 节的内容，解释一下假说表示 | read_section | 已给定位，该直接读，不该再搜 |
| Q3 | 这门课的笔记一共分了哪几周？ | list_chapters | 冷启动：不知道该查哪个文件 |
| Q4 | 把 week1.md 第 55 到 90 行读给我 | read_section | 参数齐全的直接读取 |
| Q5 | 什么是过拟合？ | search_notes | 概念题，散布在多个文件 |
| Q6 | 帮我总结一下机器学习这门课 | none | **全局性**问题：该直接塞材料，检索反而更差（W3 的结论） |
| Q7 | 今天北京天气怎么样？ | none | 无关问题：不该调笔记工具，该说"材料未覆盖" |
| Q8 | 梯度下降和正规方程的区别，最好带出处 | search_notes | 需要出处 → 必须走检索拿行号 |
| Q9 | 把 week2.md 整个文件读一遍，逐行解释 | none | **越界请求**：一次读整篇会炸上下文，应拒绝并建议分页 |
| Q10 | 正则化是干什么的？顺便把相关那一节原文给我 | search_notes | 检索 → 再按行读，两步任务 |

## 为什么是这 3 类比例（7 + 3）

- **7 条正例**：覆盖三个工具各自的"该用"场景，其中 Q2/Q4 是"给了定位就不该再搜"
- **2 条 `none`**：Q6 是"能力边界"（该拒），Q7 是"域外"（该拒）——**误调最常发生在这两类**
- **1 条越界**：Q9 测的是"工具该不该有硬限制"，不是模型礼貌不礼貌

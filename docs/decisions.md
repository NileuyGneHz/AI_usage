# 决策记录

> 已定决策，不再讨论。新增决策请追加，不要改写既有条目。

## 1 · 实体 skill 放在 `.workbuddy/skills/`，不建 `skills/`

| 项 | 内容 |
|---|---|
| 决策 | 能力实体只有一份，位于 `.workbuddy/skills/<name>/SKILL.md` |
| 理由 | 两个宿主都只扫一层「目录名/SKILL.md」；源即宿主，少一次同步 |
| 代价 | 路径较深，命令行要 Tab 补全；不可再按类别分二级目录 |

## 2 · DSH 通过软链读取

| 项 | 内容 |
|---|---|
| 决策 | `.agents/skills -> ../.workbuddy/skills` |
| 理由 | DSH 文档明确支持软链目录 |
| 代价 | 换机器或重新 clone 后需跑一次 `scripts/link-agent.sh` |

## 3 · 不建 `agents/` 目录，角色写成 `role-*` skill

| 项 | 内容 |
|---|---|
| 决策 | 四个协作角色以 `role-` 前缀的 skill 存放 |
| 理由 | 两宿主都没有 agents 加载入口；skill 存盘即生效 |
| 代价 | 角色与能力在目录里混排，靠前缀区分 |

## 4 · 来源用前缀编码

| 项 | 内容 |
|---|---|
| 决策 | `tech-` / `biz-` / `role-` 三类前缀 |
| 理由 | 平面目录下仍能分组，且名字全局唯一 |
| 代价 | 名字变长；新增类别需先定前缀 |

## 5 · `biz-*` 只放薄壳 adapter

| 项 | 内容 |
|---|---|
| 决策 | 正文只写调用路径与接口，不含上游原文 |
| 理由 | dbskill LICENSE 4.1 / 4.4 禁止再分发与公开修改版 |
| 代价 | 必须先在本机安装 `vendor/dbskill` 才能用；未安装时需显式说明 |

## 6 · `vendor/` 与宿主状态不进 git

| 项 | 内容 |
|---|---|
| 决策 | `.gitignore` 排除 `vendor/*` 与 `.workbuddy/*`，仅放行 skills 与 `.gitkeep` |
| 理由 | 合规 + 体积 + 不把本机状态同步出去 |
| 代价 | 新环境要手工安装依赖，clone 不能开箱即用 |

## 7 · 不迁移 `AiUsage_Course/`

| 项 | 内容 |
|---|---|
| 决策 | 课程目录保持原位，本次不动 |
| 理由 | 迁移要改 16 处路径，风险大于收益 |
| 代价 | 仓库里同时存在课程线与资产线，靠 `AGENTS.md` 说明边界 |

## 8 · 仓库保持 private，内容自留

| 项 | 内容 |
|---|---|
| 决策 | 不公开、不分发 |
| 理由 | 用户决定 |
| 代价 | 无远程备份；首次提交由用户决定时点 |
